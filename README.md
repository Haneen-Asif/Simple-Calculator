This project is a basic calculator made using Python functions. It can perform four basic mathematical operations.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division by zero handling

## Technologies Used

* Python

## Time Complexity

**O(1)**

The calculator performs a fixed number of operations, so the time complexity is constant.

## Space Complexity

**O(1)**

The program uses a fixed amount of memory for storing the numbers, choice, and result.
